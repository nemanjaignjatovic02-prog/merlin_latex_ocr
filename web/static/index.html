How the model reads a formula

The image is resized to a height of 96 pixels without squeezing its width and split into a grid of 16×16-pixel regions. A DenseNet-121 convolutional network describes every region, and a four-layer GRU decoder writes the LaTeX code token by token.

For every token the decoder chooses which regions to attend to and remembers what it has already read (coverage), so it does not return to the same part of the formula. The colour of a token shows how confident the model was.

Accurate mode keeps three candidates at once and picks the most likely one. Early exit is experimental: it skips the upper decoder layers when the model is confident, but in this version it sharply reduces accuracy, so it is off by default.
